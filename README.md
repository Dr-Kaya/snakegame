# Snake Game

A fun and engaging snake game built with HTML5, CSS3, and JavaScript!

## Features

- **Smooth Gameplay**: Responsive controls with arrow keys or WASD
- **Progressive Difficulty**: Game speed increases every 5 points
- **Visual Effects**:
  - Particle explosions when eating food
  - Glowing food animation
  - Gradient snake with animated eyes
  - Semi-transparent grid overlay
- **Score Tracking**:
  - Current score display
  - High score persistence (saved in browser)
  - Level progression system
- **Modern UI**:
  - Beautiful gradient backgrounds
  - Glass-morphism design
  - Responsive layout for mobile devices
  - Smooth animations
- **Game Controls**:
  - Arrow Keys or WASD to move
  - SPACE to pause/resume
  - Restart button on game over

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" button
3. Use arrow keys or WASD to control the snake
4. Eat the red food to grow and score points
5. Avoid hitting walls or yourself
6. Try to beat your high score!

## Game Mechanics

- Snake grows by 1 segment each time it eats food
- Speed increases every 5 points (new level)
- Game ends when snake hits wall or itself
- High score is saved locally in your browser

## Technologies Used

- HTML5 Canvas for game rendering
- CSS3 for styling and animations
- Vanilla JavaScript for game logic
- LocalStorage for high score persistence

Enjoy playing!
